# Contributing

Use Node.js 22 and install the locked dependencies with `npm ci`. Run `npm test`, `npm run lint`
and `npm run build` before a pull request. Do not add telemetry, ads, affiliate links, remote code,
unused permissions or secrets. New collection needs a narrow purpose, an explicit user control,
input bounds, tests and matching changes to `PRIVACY.md` and `docs/STORE_COMPLIANCE.md`.
