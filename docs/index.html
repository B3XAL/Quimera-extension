Quimera

A cookie manager that also watches your own browser for the things a proxy can never see.

Quimera is a full cookie manager first, and a small, real vulnerability engine running entirely inside the page second. A proxy only ever sees what goes over the wire, it never sees a token a single-page app quietly stashed in localStorage after the response was already rendered, a cookie that claims HttpOnly but is actually readable from document.cookie, or an auth token buried inside an unrelated-looking JSON blob.

Companion Burp Suite extension

An optional loopback bridge pairs this extension with Quimera's Burp Suite extension from the same GitHub organization, forwarding real runtime findings into Burp instead of leaving them guessed from response bodies. The bridge is off by default, requires a pairing token, and is scoped to Burp's Target Scope.
