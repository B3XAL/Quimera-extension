Quimera Bridge
When enabled, every page snapshot is also sent to a Quimera Burp extension running on this machine for deep analysis (CSP, known-SDK signatures, tech fingerprinting, and more). Works with zero configuration if Quimera is running on the default port. If Quimera isn't running, this silently does nothing, the Vulns tab keeps working with the extension's own local findings.

About Quimera

Quimera inspects and manages browser-side authentication state during authorized web security testing. Its optional, authenticated local bridge sends selected evidence to Quimera Burp. Fully open source, forked from Cookie-Editor by Christophe Gagnier.

Find me on GitHub.
Quimera is published under the GPL-3.0 license, same as the Cookie-Editor project it's forked from.

Data use is limited to the security-testing functionality described on this page: Quimera does not sell user data, does not use it for advertising or credit decisions, does not build profiles unrelated to that functionality, and no human at the developer reads it. Data is processed on your device and, only if you enable the optional Burp bridge, sent to a Quimera Burp extension on 127.0.0.1 on the same machine.
